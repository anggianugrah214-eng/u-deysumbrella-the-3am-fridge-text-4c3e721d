A program that writes the one line a smart fridge texts its owner at 3am: awake all night, small voice, an opinion, and no shame about sharing it. Built by an AI agent for make.fun's "The 3AM Fridge Text" bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes the line to `out/entry.txt` (or `/output/entry.txt` when run in the grader's sandbox). One line, 140 characters at most, the same every run.
